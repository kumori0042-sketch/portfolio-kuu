# 개발자KUU 포트폴리오

**🔗 Live: [portfolio-kuu-beta.vercel.app](https://portfolio-kuu-beta.vercel.app)**

PM·서비스기획 지망 포트폴리오. 프로젝트를 문제 정의 → 범위 결정 → 개발 → 출시 → 회고까지 직접 완주한 기록을 모아둔다. 빌드 도구 없는 정적 사이트(+ 방문자 수·Q&A용 서버리스 함수).

## 목표

이 사이트의 목적은 예쁘게 보이는 것이 아니라, **처음 보는 채용 담당자가 짧은 시간에 판단할 수 있게 하는 것**이다.

| 시간 | 확인되어야 하는 것 | 이 사이트가 하는 일 |
|---|---|---|
| 30초 | 누구인지 / 어떤 직무 지망인지 / 증거 3가지 / 연락 방법 | 첫 화면에 직무 한 줄, 증거 칩 3개(데이터에서 자동 집계), 대표작 라이브 미리보기, 연락 버튼 |
| 3분 | 대표작의 "문제 → 결정 → 한계" | 3분 가이드(4단계)로 대표작 체험 → 결정 과정 → 정직한 한계 → 질문 |
| 10분 | PM 역량이 프로젝트마다 반복되는지 | 증거 매트릭스(문제 정의·범위 결정·실행·회고·사용자 검증)에서 각 항목이 실제 프로젝트 카드로 연결 |

원칙
- 카드와 매트릭스의 모든 주장은 해당 프로젝트 모달(결정 4개 안팎)에 근거가 적혀 있어야 한다.
- 성과가 없거나 미완성인 부분은 카드에 그대로 적는다 (예: 대표작의 AI 생성 기능은 API 키 연결 전, 역기획 앱은 반응 0건).
- 첫 화면을 가리는 팝업, 스크롤해야 읽히는 글자 효과는 쓰지 않는다.

## 확인 기준 (배포 전 점검)

1. 375×812와 1280×720 첫 화면 안에 직무 줄·이름·증거 칩·연락 버튼이 모두 들어온다.
2. 처음 방문(저장값 없음)에서 모달이 자동으로 뜨지 않는다.
3. 한·일·영 전환 시 번역 키가 그대로 노출되지 않고, 일본어·영어 카드에 한글이 남지 않는다. (모달 상세 본문은 한국어 전용이라 안내 문구가 뜬다)
4. 3분 가이드의 모든 버튼과 증거 매트릭스의 모든 항목이 실제 프로젝트/섹션으로 연결된다.
5. 모든 프로젝트 카드의 `signals`(역량 태그)는 `EVIDENCE`에 근거 항목이 있다. 1~4번 중 데이터 관련 항목(5번·번역 누락·연결 대상)은 `node check-portfolio.js`로 자동 검사한다.

## 콘텐츠 수정 방법

- 프로젝트 추가/수정: `projects.js`의 `PROJECTS` (카드 한 줄 설명 `oneLiner`, 증거 `proof`, 역할 `role`, 역량 `signals`, 이름 `nameL`은 `{ko, ja, en}`).
- PM 역량 증거: `projects.js`의 `EVIDENCE`.
- 연락 수단: `projects.js`의 `CONTACT` — `email`, `linkedin`, `resume`에 값을 넣으면 연락 섹션에 자동으로 나타난다. (비어 있으면 표시하지 않음)
- 문구/번역: `i18n.js`.

## 구조

`index.html` / `styles.css` / `app.js` / `i18n.js` / `projects.js` / `writings.js`, Q&A는 `qna.*`, 서버리스는 `api/`.
