# 개발자KUU 포트폴리오

**🔗 Live: [portfolio-kuu-beta.vercel.app](https://portfolio-kuu-beta.vercel.app)**

개인 포트폴리오 랜딩 페이지. "오늘의 역기획" 프로젝트를 리서치→설계→빌드→배포→회고까지 혼자 진행한 기록을 소개한다.

- 히어로: Canvas 기반 애니메이션 그라디언트 배경 (`prefers-reduced-motion` 대응)
- 대표 프로젝트 섹션: 실제 라이브 앱을 브라우저 프레임 안에 iframe으로 임베드
- 3번의 피벗, 데모된 역량, 링크 모음(라이브 데모/GitHub/디스콰이엇/케이스 스터디)
- 라이트/다크 자동 대응 (히어로는 의도적으로 항상 다크)

빌드 도구 없는 순수 정적 사이트. `index.html` / `styles.css` / `app.js` 세 파일.
