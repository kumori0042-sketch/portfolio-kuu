FEATURED PROJECT

오늘의 역기획

PM/서비스기획 취준생을 위한 매일 3분 역기획 습관 앱. 5주 39만원짜리 코호트 스터디의 빈틈을 발견하고, 검증부터 디자인 재작업까지 전 과정을 직접 진행했습니다.

reverseengineeringstudyapp.vercel.app
문제

역기획이 PM 취준생의 유일한 자체 포트폴리오 수단이지만, 기존 방법은 5주 코호트(30~40만원)나 완전 혼자 하는 것뿐이었습니다.

아키텍처

BYOK 구조로 백엔드 없이 정적 사이트로 설계 — AI 호출은 사용자 키로 브라우저에서 직접, 서버 비용을 거의 0에 가깝게 만들었습니다.

검증

정식 인터뷰 대신 라이브 앱에 가격 페이크도어를 심어 실제 반응을 수집하는 구조로 전환했습니다.

HOW I BUILT IT

3번의 방향 전환

정답을 처음부터 알았던 게 아니라, 매번 근거를 보고 방향을 바꿨습니다.

01

브레인스토밍 앱 → 역기획 앱

막연한 아이디어 수집 앱에서, PM 면접 과제 포맷과 정확히 겹치는 역기획 기반으로 컨셉을 좁혔습니다.

02

인터뷰 먼저 → 출시 먼저

WTP 인터뷰 스크립트까지 준비했지만, 형식적 인터뷰보다 실제 배포 후 반응이 더 정직한 신호라고 판단해 방향을 틀었습니다.

03

편집적 디자인 → 토스 스타일

세리프 헤드라인의 실험적 디자인을 사용자 피드백을 받고 전면 재작업 — 실배포 제품과 리포트의 디자인 기준은 다르다는 걸 배웠습니다.
